1. WHAT IS THIS PROJECT?
================================================================================

ParkSmart is a smart parking management system that helps people book parking 
slots online. Users can see available parking spaces, book them, pay online, 
and manage their bookings. Admin can monitor all bookings and manage the 
parking area.

================================================================================
2. WHO CAN USE THIS SYSTEM?
================================================================================

TWO TYPES OF USERS:

A) REGULAR USERS (People who want to park vehicles)
   - Register and login to the system
   - View available parking slots
   - Book parking slots for their vehicles
   - Make online payments
   - Edit or cancel bookings
   - Check weather conditions
   - Get directions to parking area
   - Submit reviews and feedback
   - View booking history

B) ADMIN (Parking manager)
   - Monitor all parking entries and exits
   - Track vehicle entry/exit times
   - View all user bookings
   - See payment records
   - Read user reviews and feedback
   - Generate reports
   - Manage parking slots

6. HOW TO USE THE SYSTEM
================================================================================

FOR USERS:

Step 1: REGISTRATION
   - Go to registration page
   - Enter: Username, Email, Password
   - Click "Register"
   - Login with your credentials

Step 2: VIEW AVAILABLE SLOTS
   - Click "Slots" in navigation
   - See all available parking slots
   - Filter by vehicle type if needed
   - Check slot details

Step 3: BOOK A SLOT
   - Click on available slot
   - Enter vehicle number
   - Select booking date
   - Choose start time
   - Set duration (hours)
   - Click "Proceed to Payment"

Step 4: MAKE PAYMENT
   - Review booking details
   - Check total amount
   - Enter payment details
   - Confirm payment
   - Get booking confirmation

Step 5: MANAGE BOOKINGS
   - Go to "Bookings" page
   - View all your bookings
   - Edit booking (change date/time)
   - Cancel booking (get refund)

Step 6: CHECK WEATHER
   - Click "Weather" in navigation
   - See current parking area weather
   - Read parking recommendations
   - Plan your visit accordingly

Step 7: GET DIRECTIONS
   - Click "Map" in navigation
   - Allow location access
   - Click "Get Directions"
   - Follow map to parking area

FOR ADMIN:

Step 1: LOGIN
   - Use admin credentials
   - Access admin dashboard

Step 2: VEHICLE ENTRY
   - Click "Entry" in navigation
   - Enter vehicle details
   - Assign parking slot
   - Record entry time

Step 3: VEHICLE EXIT
   - Click "Exit" in navigation
   - Enter vehicle number
   - System calculates charges
   - Process payment
   - Mark slot as available

Step 4: MONITOR REVIEWS
   - Click "Reviews" in navigation
   - View all user reviews
   - Filter by rating/date
   - Track customer satisfaction

Step 5: VIEW REPORTS
   - Check dashboard statistics
   - Monitor active bookings
   - Track revenue
   - Generate reports
